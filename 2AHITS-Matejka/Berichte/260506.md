## Übung (curl und Notenmanagement)

```sh
curl 'https://notenmanagement.htl-braunau.at/rest/api/LFs/3927' 
...
```
```
{"LF_ID":3927,"Datum":"2026-04-22T00:00:00","Lehrer_ID":1096,"Klasse":"2AHITS","Fach":"ITP2PM","Typ":"Test","MaxPunkte":15.0,"Kommentar":"3ter Test","Notenspiegel":[9,5,7,1,4,0]}
```

## Beispiel Daten anfordern

```sh
curl 'https://notenmanagement.htl-braunau.at/rest/api/Schueler/1011'
```

## Daten der Lehrer anfordern

```sh
curl 'https://notenmanagement.htl-braunau.at/rest/api/Lehrer?Parameter'
```

## Liefert alle Klassen

```sh
curl 'https://notenmanagement.htl-braunau.at/rest/api/Klassen?Parameter'
```

## Liefert alle Leistungsfeststellungen einer Klasse

```sh
curl 'https://notenmanagement.htl-braunau.at/api/Klassen/2AHITS/Faecher/ITS1/LFs?Parameter'
```

## Liefert alle Fächer mit Eintragungen (Leistungsfeststellung oder Frühwarnung) für einen bestimmten Schüler

```sh
curl 'https://notenmanagement.htl-braunau.at/api/Schueler/1011/Faecher?Parameter'
```

## Liefert alle Benutzernachrichten

```sh
curl 'https://notenmanagement.htl-braunau.at/api/BenutzerNachrichten?Parameter'
```

## Liefert die Daten alle Nachhilfelehrer

```sh
curl 'https://notenmanagement.htl-braunau.at/api/Nachhilfelehrer'
```

## Liefert die Daten aller Nachhilfesuchenden.

```sh
curl 'https://notenmanagement.htl-braunau.at/api/Nachhilfesuchende/{MatrikelNr}'
```
