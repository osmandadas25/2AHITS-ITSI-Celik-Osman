## Übung (Tage bis zum Ball) 

*Schreibe ein Shell-Skript das die Anzahl der Tage bis zum HTL Ball ermittelt. Das Datum des Balls soll am Anfang des Skripts in einer Variable stehen. Die Ausgabe soll in der folgenden Form sein:*

```bash
#!/bin/bash

BALL_DATE="2027-01-15"

current_seconds=$(date +%s)

ball_seconds=$(date --date="$BALL_DATE" +%s)

diff_seconds=$((ball_seconds - current_seconds))
diff_days=$((diff_seconds / 86400))

echo "Es sind noch $diff_days Tage bis zum HTL Ball ($BALL_DATE)"
```

## Übung (Datierte Kopie V1)

*Schreibe ein Skript, das einen Dateinamen als erstes Argument übernimmt und eine datierte Kopie der Datei anlegt. Heißt die Datei z.B. file1.txt und ist heute der 2026-10-13, so soll die Kopie 2026-10-13_file1.txt heißen. Hinweis: Verwende command substitution und das Kommando date.*

```bash
#!/bin/bash

namedatei=$1

datum=$(date +%Y-%m-%d)

cp "$namedatei" "${datum}_$namedatei"
```

## Übung (Datierte Kopie V2)

*Challenge: Erweitere das Skript so, dass das Datum nach dem Dateinamen und vor der Endung steht, z.B. file1_2026-10-13.txt. Hinweis: Verwende cut, um den Dateinamen von der Endung zu trennen, z.B. echo "filename.ext" | cut ... !Überlege: Was passiert bei Dateien wie archiv.tar.gz oder README (ohne Endung)?*
### cut - remove sections from each line of files
### -d, --delimiter=DELIM: use DELIM instead of TAB for field delimiter
### -f, --fields=LIST: select only these fields;  also print any line that contains no delimiter character, unless the -s option is specified

```sh
#!/bin/bash

namedatei=$1

datum=$(date +%Y-%m-%d)

name=$(echo "$namedatei" | cut -d "." -f 1)
endung=$(echo "$namedatei" | cut -d "." -f 2)

cp "$namedatei" "${name}_${datum}.${endung}"
```

## Übung (Datierte Kopie V3)

*Challenge: Erweitere das Skript aus V2 so, dass es eine beliebige Anzahl von Dateien als Argumente akzeptiert und von jeder eine datierte Kopie anlegt. Hinweis: Verwende $@ (siehe Kapitel Argumentliste). Alternativ kann auch das Kommando xargs nützlich sein.*

```sh
#!/bin/bash

datum=$(date +%Y-%m-%d)

for namedatei in "$@"
do
    name=$(echo "$namedatei" | cut -d "." -f 1)
    endung=$(echo "$namedatei" | cut -d "." -f 2)

    if [[ "$name" == "$namedatei" ]]; then
        cp "$namedatei" "${namedatei}_${datum}"
    else
        cp "$namedatei" "${name}_${datum}.${endung}"
    fi
done
```
