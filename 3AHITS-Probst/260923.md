 # Scripts in Shell

#### Script erstellen und bearbeiten: vim +startinsert hello-World.sh

#### Speichern und verlassen: Esc -> :wq -> Enter

#### Ausführen: sh ./hello-World.sh 
Hello World

#### Damit man ./Dateiname.sh funktioniert muss man:
- ""#!/bin/bash" am Anfang der Datei eingeben
- die Datei muss auführbar gemacht werden: chmod +x hello-World.sh

#### In der Datei Variablen anlegen: $1, $2 usw.    

#### Argumente weitergeben: sh ./args.sh fn fn fn

## Möglichkeiten mit Argumenten:

- **Einzelne Argumente ausgeben:** echo $1, echo $2, echo $3
- **Anzahl der Argumente ausgeben:** echo $#
- **Alle Argumente ausgeben:** echo $@
- **Scriptname ausgeben:** echo $0
