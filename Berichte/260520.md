# wc
## Gibt die Anzahl der Zeilenumbrüche, Wörter und Bytes für jede Datei aus.

- -m: Zeichenanzahl ausgeben
- -l: Zeilenumbruchanzahl ausgeben
- -L: Die maximale Anzeigebreite ausgeben
- -w: Wortanzahl ausgeben

```sh
$ echo eins zwei drei | wc - klassenkassa.csv
```
### gibt die kumulierte Anzahl der Zeilenumbrüche, Wörter und Bytes aus. (ausgebener Text + Datei)


# cut
## Abschnitte aus jeder Dateizeile entfernen

- -f: Nur bestimmte Felder werden ausgewählt; außerdem werden alle Zeilen ausgegeben, die
kein Trennzeichen enthalten, es sei denn, die Option -s ist angegeben.

- -c: Nur bestimmte Zeichen auswählen

# sed
## Stream-Editor zum Filtern und Transformieren von Text

## Übung (HTML nach Markdown Konverter)

```sh
sed \
-e 's/<html>//g' \
-e 's/<body>//g' \
-e 's/<h1>/# /g' \
-e 's/<\/h1>//g' \
-e 's/<h2>/## /g' \
-e 's/<\/h2>//g' \
-e 's/<p>//g' \
-e 's/<\/p>//g' \
-e 's/<b>/**/g' \
-e 's/<\/b>/**/g' \
-e 's/<i>/*/g' \
-e 's/<\/i>/*/g' \
-e 's/<code>/```/g' \
-e 's/<\/code>/```/g' \
log.html > log.md
```
